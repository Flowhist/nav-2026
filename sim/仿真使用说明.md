# 仿真使用说明

> 进入 `/home/embotic/nav_workspace` 路径

### step 0. 环境准备

```bash
source install/setup.bash

export FINAV_REPO_DIR=$PWD/src/finav

export FINAV_MAPS_DIR=$PWD/src/finav/maps
```



# 路径规划仿真

### step 1. 启动路径规划仿真

```bash
ros2 launch finav path_plan_sim.launch.py
```

### step 2. 在 RViz 中测试

使用 `2D Pose Estimate` 设置起点

使用 `2D Goal Pose` 设置终点

查看 `/plan` 路径结果



# 建图仿真

### step 1. 启动 Gazebo 建图仿真

```bash
ros2 launch finav map_sim.launch.py
```

### step 2. 启动键盘控制

另开一个终端：

```bash
source install/setup.bash

ros2 run finav base_control_router.py
```

### step 3. 保存地图

建图完成后另开一个终端：

```bash
source install/setup.bash

./src/finav/scripts/tool/save_map.sh
```



# 导航仿真

### step 1. 启动导航仿真

```bash
ros2 launch finav nav_sim.launch.py
```

### step 2. 指定地图启动

```bash
ros2 launch finav nav_sim.launch.py map_file:=map4
```

### step 3. 启动控制路由

另开一个终端：

```bash
source install/setup.bash

ros2 run finav base_control_router.py --ros-args --params-file src/finav/config/base_control.yaml
```

> 作用：把 `/nav_cmd_vel` 转发/仲裁到 `/cmd_vel`，否则仿真车不会动。

### step 4. 在 RViz 中测试

使用 `2D Pose Estimate` 设置初始位置

使用 `2D Goal Pose` 设置导航目标

查看 `/plan`、`/nav_cmd_vel`、`/cmd_vel`

### step 5. 仿真自动重定位

```bash
ros2 launch finav nav_sim.launch.py relocate:=true
```



# 地点导航仿真

### step 1. 启动带地点显示的导航仿真

```bash
ros2 launch finav nav_sim.launch.py show_locations:=true
```

### step 2. 启动控制路由

另开一个终端：

```bash
source install/setup.bash

ros2 run finav base_control_router.py --ros-args --params-file src/finav/config/base_control.yaml
```

### step 3. 注册地点

另开一个终端：

```bash
source install/setup.bash

ros2 run finav annotate_tool.py
```

### step 4. 从终端选择已注册地点导航

另开一个终端：

```bash
source install/setup.bash

ros2 run finav nav_to_location.py
```
