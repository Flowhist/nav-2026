# 人员跟随接口与实现

正式模块位于 `scripts/vision/` 和 `scripts/control/person_follow.py`，入口为 `launch/person_follow.launch.py`。原 demo 已迁移删除。环境部署见 [部署与运维](../部署与运维.md#视觉推理环境)，使用步骤见 [操作指南](../操作指南.md#人员跟随)，测试记录见 [开发与验证](../开发与验证.md#人员跟随验证)。

## 数据链

`Gemini 305 -> vision.camera -> vision.tracker_node -> person_follow -> /follow_cmd_vel -> base_control_router -> /cmd_vel`。

相机是唯一 SDK 采集入口，进程锁防止本模块重复打开设备。发布纠正倒置后的 RGB、对齐深度和内参；避障复用同批图像的 160x120 深度。默认采集处理上限 15 Hz，回调仅保存最新帧。其他 SDK 使用者仍须先退出，文件锁不能约束外部驱动。

推理采用 YOLOv8n 320 + Ultralytics 8.3.253 的原生 BoT-SORT（含低分关联、稀疏光流相机运动补偿）+ OSNet x0.25。OSNet 使用官方 MSMT17 combineall 人物重识别权重，不使用 ImageNet 分类特征代替。两张静态 batch=1 TensorRT FP16 引擎在本机生成；CPU PyTorch 仅用于导出和关联前后处理。权重、引擎、上游 OSNet 源码及许可证位于用户缓存，不进入仓库。

身份管理独立于跟踪 ID：高质量观测连续 3 帧登记，最多保存 8 个归一化特征；相似度不足、多人相似度接近、框模糊/截断/遮挡、深度无效或位置跳变时停止。遮挡后可用特征恢复到新 ID，但须重新连续确认；超过 3 秒未匹配须重新选人。只有高置信、高相似度观测更新特征库，未观察到的人不会以预测坐标继续输出运动。身份库仅在内存中，退出即清除。

RGB-D 约束复用原躯干深度中位数与离散度拒绝、URDF 外参投影，并增加位置变化上限。这里的空间门限在车体坐标中计算，尚无里程计补偿；快速相机运动时可能保守停车。阈值是初始配置，仍需现场交叉、遮挡和光照数据标定，不能保证始终辨对人。

## ROS 契约

| 话题 | 类型 | 约定 |
| --- | --- | --- |
| `/vision/color` | `sensor_msgs/Image` | rgb8，640x480，Best Effort |
| `/vision/depth` | `sensor_msgs/Image` | 32FC1，米，640x480，Best Effort |
| `/vision/camera_info` | `sensor_msgs/CameraInfo` | 与上述图像相同采集时间戳和 frame |
| `/avoidance/depth`、`/avoidance/camera_info` | Image、CameraInfo | 160x120；4x4 最小值，零深度保留未知 |
| `/follow/target` | `finav/FollowTarget` | 源图像时间、session、递增 sequence、track_id、base_link XYZ、置信度、相似度、valid、state |
| `/follow/status` | `std_msgs/String` | JSON：目标状态与当前人物 ID、置信度、质量 |
| `/follow/control_status` | `std_msgs/String` | JSON：drive、门控状态、建议/输出速度，约 1 Hz |
| `/follow/command` | `std_msgs/String` | JSON：`{"action":"select","track_id":1}`、`{"action":"enroll"}`、`{"action":"cancel"}` |
| `/follow_clear` | `std_msgs/Empty` | 仲裁取消，锁定至进程重启 |
| `/follow_cmd_vel` | `geometry_msgs/Twist` | 仅 drive 模式发布，20 Hz；永不直接发布 `/cmd_vel` |

图像 frame 为 `front_camera_upright_optical_frame`；目标坐标为 `base_link`，+x 向前、+y 向左、+z 向上。图像按 SDK 系统采集时间换算 ROS 时间，不以推理完成时间刷新有效期。视觉进程订阅精确同步消息、保留最新一组；过期、乱序或重复结果不能续期。

参数集中于 `config/person_follow.yaml` 和 `config/person_tracker.yaml`。默认跟随间距 2.1 m（车体原点计量），不倒车；距离大于 5 m 或小于等于间距时停车；方位大于 25 度只转向。上限 0.15 m/s、0.3 rad/s，增加加速限制，失效停车不做缓慢减速。

独立控制循环检查源时间与接收时间，350 ms 过期即输出零速。超声使用四路 0x10–0x13，任一路距离不大于 0.5 m、缺失、重复、无效或超过 500 ms 均停车。沿用 DCCS `KS114State`，逐探头时间戳检查，重发缓存不续期。第二个目标/速度发布者、推理 session 改变、取消会锁定停止，须重启跟随。

控制默认观察；取消后应退出整个跟随 launch，避免持续零速与导航输入冲突。仲裁契约见 [导航接口](导航接口.md)。跟随尚未使用独立避障的绕障结果，超声盲区和完整转弯扫掠未获保护，不自动启用行驶。

## 上游来源

- [Ultralytics tracking](https://docs.ultralytics.com/modes/track/)：BoT-SORT 与 YOLO 使用其 AGPL-3.0 / 商业许可条款。
- [OSNet 源码](https://github.com/KaiyangZhou/deep-person-reid/tree/f8cd150fdf77e8d9e1ed143b7f308c2c609ded50)、[官方模型表](https://kaiyangzhou.github.io/deep-person-reid/MODEL_ZOO.html)：MIT 源码，模型训练数据的使用条件另行适用。
- 模型缓存 `manifest.json` 记录源码提交、权重来源、TensorRT 版本和各文件 SHA256。TensorRT 引擎不可作为跨设备通用文件分发，换设备/运行库后重新生成。
