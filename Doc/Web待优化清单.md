# Web 待优化清单

复核与实施日期：2026-09-17。前 11 项确认存在实现缺口；第 12 项是维护改进，不作为功能故障。以下实现已完成离线验证，未重启真实服务、未执行运动测试。README 只维护当前功能、操作和接口说明。

## P1

- [x] **地图删除与路径边界**：复现了 `.` 指向地图根目录及字符串前缀越界。现统一校验地图名、拒绝根目录/目录链接，按真实路径判断静态文件归属；建图、导航、重定位或存图期间禁止删除。验证：异常路径不删除文件，活动服务返回 409。[实现](../server/server_app.py)
- [x] **请求校验**：确认坏 JSON 曾被转换为空对象并可能触发默认操作。现校验 JSON 对象、必填坐标、有限数值、查询范围、类型和请求大小，错误返回 4xx。验证：无效请求不入队、不改配置。[实现](../server/web_support.py)
- [x] **指令受理与过期**：确认离线可入队、队列满仍报成功。现拒绝离线/满队列，合并手动输入并设置 300 毫秒有效期；停止/取消单独保留并优先处理，取消清除待执行普通命令。验证：离线、满队列、过期、停止优先级。[实现](../server/ros_bridge.py)
- [x] **配置可靠性**：确认仅有前端局部检查、后端直接覆盖。现执行 YAML 解析与基本结构校验、内容版本检查和原子替换，移除前端伪校验。验证：非法内容、并发写入、旧版本、替换失败均保留正确文件。[实现](../server/web_support.py)
- [ ] **访问控制易用性（暂缓）**：按调试阶段要求，口令登录默认关闭；保留 `FINAV_WEB_AUTH=1` 显式启用入口，跨站写入与内容类型检查仍生效。已验证默认直接访问及显式启用后的鉴权；后续再改善登录、口令管理与会话体验。设置见 [服务部署](服务部署.md#web-访问)。

## P2

- [x] **存图反馈**：确认旧实现不跟踪退出状态。现返回任务 ID，状态区记录运行/成功/失败和错误尾部，120 秒超时；前端完成后刷新，退出时回收存图进程组。验证使用模拟进程，不执行真实存图。[实现](../server/ros_bridge.py)
- [x] **就绪与连接状态**：原有 systemd 查询和传感器提示确实存在，本次补齐统一就绪状态与 30 秒等待提示；HTTP、ROS、SSE 分别记录，互不覆盖。无目标时不要求 `/plan`；清理场景同时清理规划覆盖层。[后端](../server/state_store.py)、[前端](../server/web/app-api.js)
- [x] **事件恢复**：确认重启后旧游标会屏蔽新事件。现加入服务会话 ID、游标重置与截断提示，分页按序返回而非直接跳到尾部；前端同时重置场景版本。[实现](../server/state_store.py)
- [x] **资源与退出**：确认连接/请求缺少边界及 ROS 未主动关闭。现限制 32 个连接、8 个 SSE、4 MiB 请求体和 10 秒读写超时；退出关闭连接及 executor/node/context。已验证连接边界与模拟 ROS 清理，实机退出行为仍需现场验收。[实现](../server/web_support.py)
- [x] **地点一致性**：编辑文档原本已有原子保存及版本检查，缺口仅在双写与旧接口绕行。现地点写入统一到 `.editor.yaml`，Web/语音导航/RViz 共用优先读取该文档的逻辑；旧 `.locations.yaml` 仅兼容导入。验证旧文件导入、版本冲突、写入失败后读者一致。[共享读取](../scripts/map_location/location_utils.py)
