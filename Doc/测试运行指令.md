# 移动

### step 1. 启动底盘 CAN、STM32 手柄通信与控制路由（建图/导航都需要）

```bash
source install/setup.bash

./src/finav/base_drive.sh
```



# 建图

### step 1. 启动slam-toolbox建图服务

```bash
source install/setup.bash

export FINAV_REPO_DIR=$PWD/src/finav

export FINAV_MAPS_DIR=$PWD/src/finav/maps

ros2 launch finav map.launch.py
```

### step 2. 启动rviz查看效果

> 远程桌面：sudo ./start_vnc.sh
>

```bash
source install/setup.bash

rviz2 -d src/finav/rviz/mapping.rviz
```

### step 3. 保存地图

```bash
./src/finav/scripts/tool/save_map.sh
```

### step 4. 编辑地图

地图编辑已整合进 Finav Web 页面，无需另行启动编辑器进程。打开 Finav 的“地图”页，选择地图后点击“编辑地图”。

编辑模式可维护地点、可旋转矩形禁行区和巡航路线，操作会自动保存到地图目录中的 `<地图名>.editor.yaml`。地点同时同步到 `<地图名>.locations.yaml`，供导航页和 ROS 节点使用。

“导出衍生地图”会复制地点和路线，并把禁行区写入新的地图栅格。源地图不会被修改。

地点统一在 Web 页面维护，不再提供本地手动注册脚本。

# 导航

### step 1. 启动slam-toolbox导航服务

```bash
source install/setup.bash

export FINAV_REPO_DIR=$PWD/src/finav

export FINAV_MAPS_DIR=$PWD/src/finav/maps

ros2 launch finav nav.launch.py
```

### step 2. 启动rviz查看效果

> 远程桌面：sudo ./start_vnc.sh

```bash
source install/setup.bash

rviz2 -d src/finav/rviz/navigation.rviz
```

### step 3. 手动重定位

导航链路启动后，另开一个终端执行一次：

```bash
source install/setup.bash

ros2 run finav nav_relocate.py
```

也可以指定地图：

```bash
source install/setup.bash

ros2 run finav nav_relocate.py --ros-args -p map_file:=longcorridor
```
