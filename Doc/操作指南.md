# 操作指南

适用于已按 [部署与运维](部署与运维.md) 安装并启动服务的机器。打开 `http://<机器人IP>:8010`，开始运动前确认现场安全、手柄回中，并先查看底盘与手柄状态。

## 第一次操作

1. 建图页开始建图，完成后保存地图并停止建图。
2. 地图页编辑地点、禁行区和开放路线。
3. 导航页选择地图、启动导航，核对定位后下发目标点或路线。
4. 测试结束，按部署文档停止整套服务。

## 建图

建图页显示地图和雷达，可开始建图、保存地图及结束建图。结束建图或运行期间确认离开建图页不会自动保存地图，请先等待保存成功。

建图与导航互斥。已有完整地图需要扩图时，使用下方“继续建图”流程。

## 导航

1. 选择地图并启动导航。
2. 核对机器人位置、朝向与雷达在地图中的对齐情况。需要时手动设置初始位姿或自动重定位；自动候选发布成功不代表定位已经正确。
3. 设置目标点，或选择零散地点、路线终点名字、已保存的开放路线。
4. 路线可暂停、继续或取消；不要求从起点开始，反向执行时车头仍朝行进方向，到端点停车。手柄接管会取消任务。
5. 结束导航或运行期间确认离开导航页会停止导航服务。

“导航速度”可设置直行上限（0.05–0.60 m/s）、原地转向及行进转向上限（1–28.6 °/s）。保存后会尝试应用到当前导航；若提示“已保存、当前导航未确认应用”，下次启动才会读取保存值。最终速度仍受手柄档位比例、路线限速与底盘硬限约束。

导航底图默认固定使用保存的 YAML/PGM，雷达、位姿与路径仍实时更新。底图不刷新属于正常行为；定位仍依赖位姿图，画笔编辑不会同步修改定位扫描。参数与限制见 [地图、定位与 TF](reference/导航接口.md#地图定位与-tf)。

## 地图编辑

- 支持地点、禁行区、开放路线编辑、路线平滑、导出与删除。
- 路线“终点名字”用于目的地导航及语音匹配；避免与零散地点重名。详细匹配规则见 [导航接口](reference/导航接口.md#常用接口)。
- 进入“编辑”后选择“画笔”，可绘制占据（黑）、可通行（白）、未知（灰）。方形笔刷边长为 1–40 格，支持撤销、保存和取消。
- 栅格保存前须停止建图、导航及重定位。保存会检查地图版本，上一版保存在同目录的 `<图像文件名>.brush-backup`。此操作不修改 `.posegraph/.data`，从位姿图重建的地图不会自动包含笔画。
- 地点、禁行区和路线保存时会检查版本冲突；遇到冲突应重新读取，避免覆盖他人修改。
- 删除地图前须停止建图、导航和重定位，并等待存图结束。

## 继续建图

建图页选择具有 `.yaml/.pgm/.posegraph/.data` 的地图，点击“继续建图”。
只有栅格图或序列化数据缺失的地图不会出现在续建候选中。

1. 加载后处于定位模式，不向旧位姿图追加建图节点。
2. 点击“手动重定位”，在地图上拖动指定位置和朝向；也可点击“自动重定位”。
3. 用户目视核对机器人位置、朝向、雷达与墙体的对齐情况。
4. 直接点击“开始续建”，无需等待算法匹配状态或二次确认弹窗。
5. 扩展区域后保存地图，使用新的地图名，最后结束建图。

“匹配已更新”表示 STB 接受了定位扫描，不保证定位正确；全局重定位进程成功
退出也只表示候选位姿已发布，不会自动切换建图。匹配状态只供参考，是否对齐由
用户判断；地图未加载、节点状态过期、正在重定位或停止时仍禁止切换。
节点重启后始终重新进入定位阶段。

旧图上的画笔编辑只存在于 PGM，不会同步改变位姿图；续建生成栅格时不保证
保留画笔编辑。续建另存时会自动继承源地图保存过的地点、路线、禁行区和编辑设置，
包括地点朝向、路线速度等；旧版地点文件也支持导入。继承使用点击保存时的编辑信息，
保持地图世界坐标不变，不随栅格原点变化平移。地图文件与编辑信息均保存完成后才报告成功。
源地图不变；若目标地图已有编辑文档或旧版地点文件，则保留其现有内容。
安全净空只有标记为 `editor_override` 时使用地图保存值，其余情况跟随当前规划配置；
修改 `path_plan.yaml` 后需重新启动导航，地图编辑器也按当前配置显示默认净空。
回环优化可能改变局部地图形状，使用前请核对地点、路线和禁行区是否仍与新图对齐。

实现入口和隔离验证要求见 [开发与验证](开发与验证.md#继续建图开发)。

## 配置与服务操作

配置页可查看和编辑导航及底盘的 YAML 配置。调参前保留原始备份；保存时检查语法、基本结构和版本冲突，保存后按页面提示使配置生效。

底盘配置通过顶栏“⋯”菜单中的“重启底盘控制”应用，该操作会停止当前建图或导航，Web 保持运行。整套重启只恢复底盘与 Web；“关闭 Finav 服务”不会关闭 Jetson 系统。

## 状态与手动控制

避障和观测统一由右上角“系统”中的“避障”开关控制，默认关闭。开启时启动观测并接入控制矫正；关闭时先让底盘退出避障，再停止相机、超声和避障服务。避障关闭时不能单独开启观测。切换前松开摇杆并取消导航。开关接口与实车验证限制见 [避障接口](reference/避障接口.md#控制意图与开启方式)。

顶部“避障可视化”打开俯视图，车头朝上、左侧为 +Y。低饱和填色与连续边界表示深度轮廓，彩色短弧表示四路超声的实际回波位置。回波近于 0.5 m 为红色，0.5–1 m 为黄色，更远为绿色；弧宽仅是示意，不是物体实际宽度。可切换显示范围及两类图层。空白区域不代表无障碍。

开启避障后，页面显示“实时观测”即可查看回波。重新进入网页会显示服务实际状态；设备占用或启动失败时显示原因。数据中断后回波自动消失，切换页面不会停用避障。

建图和导航页底部的运行状态中心汇总就绪条件、地图/雷达/里程计/TF 新鲜度与频率、机器人位姿、目标、路径、手柄和日志。展开不会切换页面或清理任务；服务进程存活不等于已就绪，启动超过 30 秒仍缺少关键数据会显示未就绪，无目标时不要求存在路径。

事件可按级别和保留条数筛选，重启 Web 后恢复读取，历史截断会提示。

虚拟摇杆与键盘控制经底盘仲裁器执行，页面切换、失焦或隐藏时执行停止逻辑。控制量按共用的 1–5 档缩放；档位不在线时拒绝非零输入，手柄抢停后需将网页控制回中。档位属于设备运行状态，不保存到导航 YAML；触摸屏档位同步仍需实机验收。

## 人员跟随

先完成 [视觉环境部署](部署与运维.md#视觉推理环境)，确认相机没有其他 SDK 使用者。当前相机倒置，默认同时旋转 RGB 和对齐深度。启动无需地图、导航或 Web：

```bash
source /opt/ros/humble/setup.bash
source /home/embotic/DCCS/install/local_setup.bash
source /home/embotic/nav_workspace/install/local_setup.bash
ros2 launch finav person_follow.launch.py
```

默认观察模式不发布速度。用 `ros2 topic echo /follow/status` 查看人物 ID 与身份状态，`ros2 topic echo /follow/control_status` 查看控制门控。单人连续稳定观测后自动登记；多人时先查看 ID，再明确选择：

```bash
ros2 topic pub --once /follow/command std_msgs/msg/String '{data: "{\"action\":\"select\",\"track_id\":1}"}'
```

短时丢失后重新确认身份；超过恢复窗口显示 `reselect_required`，重新选人或发送 `{"action":"enroll"}` 恢复单人登记。显式取消：

```bash
ros2 topic pub --once /follow_clear std_msgs/msg/Empty '{}'
```

取消锁定后须 Ctrl+C 退出整套跟随，重新启动才能恢复，不能通过重新选人绕过取消。

行驶前须现场确认环境安全、测距与方向正确、四路超声驱动在线，底盘仲裁器支持 `/follow_cmd_vel`。停止导航控制，退出观察实例，再显式使用 `ros2 launch finav person_follow.launch.py drive:=true`。这不是运动验收完成的声明；超声覆盖、外参和遮挡交叉仍需现场验证，独立避障尚未接入跟随。

若共享相机已启动，追加 `start_camera:=false`；单独启动相机使用 `ros2 launch finav vision_camera.launch.py`。安装与超声诊断见 [驱动与依赖](reference/驱动与依赖.md#ks114-安装与历史验证)，话题和参数见 [人员跟随接口](reference/人员跟随.md)。

## 地图文件与备份

地图保存在 `maps/`。同一地图的 YAML/PGM、SLAM 位姿图与扫描数据（`.posegraph/.data`）以及编辑文档应一起备份，保持同一坐标系。

地点、禁行区、路线和编辑设置统一保存于 `maps/<地图名>/<地图名>.editor.yaml`。缺少编辑文档时兼容旧 `.locations.yaml`，之后不再双写地点文件。

地图默认被 Git 忽略，推送代码不会备份地图。
