- 根 README 只保留项目简介、最短启动步骤和导航；原 Wiki 仅作为旧入口跳转。
- 操作指南负责操作步骤，部署文档负责安装和服务管理，reference 负责接口与依赖，模块 README 负责内部实现。
- 同一命令、接口或规则只在所属文档完整维护，其他文档使用链接。
- plans 保存设计目标与实施阶段；已实现行为和验证记录更新到对应参考或开发文档，并回链。
- 改功能时同步修改所属文档。明确区分待实现、已实现、已部署及离线/实机验证；历史数据注明日期和限制。
- 移动文件时更新相对链接和标题锚点；缺失的报告或测试入口要显式标注，不能当作当前可执行步骤。
