Finav 只保留网络传输、HE 协议解析、LaserScan 发布和阴影滤波；厂商 launch、自定义消息和命令服务未导入。本地修改包括：

- 支持左右两个驱动实例。
- 使用 SensorDataQoS (Best Effort)。
- 修正首帧/NTP 时间戳和扫描周期。
- 保留 `/scan_left` + `/scan_right` -> `/scan` 的外部契约。

### 编译依赖

- ROS 2：`rclcpp`、`sensor_msgs`、`geometry_msgs`。
- Ubuntu：`libboost-thread-dev` (`1.74.0.3ubuntu7`)。

`CMakeLists.txt` 已显式链接 `Boost::thread`，但 `package.xml` 尚未声明 Boost rosdep key；新机部署时需显式安装，后续应补齐 manifest。

厂商包未提供许可证文件，manifest 中的 license 为 `TODO`。对外分发前必须向厂商确认授权。

## 4. DM-IMU 与 STM32 手柄

- DM-IMU 协议：`third_party/dm_imu/dm_imu_modules/modules/`。
- ROS 节点：`scripts/imu/dm_imu_publisher.py`。
- 一次性配置：`scripts/imu/config_dm_imu.py`。
- STM32 手柄：`scripts/handle/`，配置见 `config/handle.yaml`。
