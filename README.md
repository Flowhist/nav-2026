# Finav

Finav 是基于 ROS 2 Humble 的实机建图与导航项目，包含双雷达、IMU、EKF、SLAM Toolbox、自研规划与路径跟踪、Web 调试后台及仿真入口。底盘驱动、手柄和控制仲裁由同级仓库 `base_control` 负责。

## 快速入口

新机器先完成 [部署与运维](Doc/部署与运维.md) 中的依赖准备、构建和服务安装。已安装服务的机器，在确认现场安全、手柄回中后，由机器人用户执行：

```bash
systemctl --user start finav.target
```

打开 `http://<机器人IP>:8010`，按 [操作指南](Doc/操作指南.md) 建图或导航。建图与导航按需启动，不能同时运行。结束使用时：

```bash
systemctl --user stop finav.target
```
